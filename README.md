# Luo-fe 本地提示词管理器 v1.4.1

一款专为 AI 文生图设计的本地提示词管理与组合工具，帮助用户高效组织、选择和导出提示词组合。

## v1.4.1 性能优化

全面性能优化，降低运行时内存占用和 CPU 使用率，所有功能保持不变：

- **LRU 图片缓存** — 提示词图片缓存从无上限改为 LRU 策略（最大 20 条），消除内存泄漏
- **防抖保存频率** — 提示词使用记录保存改为防抖机制，I/O 频率降低 90%+
- **缓存常用提示词** — 常用提示词计算结果缓存，避免每次渲染重复扫描
- **按需注册鼠标事件** — 面板拖拽的 mousemove/mouseup 监听器改为仅在拖拽时注册，空闲时零开销
- **缓存快捷键解析** — 快捷键字符串解析结果缓存，避免每次按键重复解析
- **搜索短路优化** — 搜索时避免冗余 `toLowerCase()` 调用，text 已匹配时跳过翻译检查
- **离屏渲染跳过** — 滚动列表添加 `content-visibility: auto`，浏览器自动跳过离屏元素渲染
- **面板渲染隔离** — 面板添加 `contain: layout paint style`，隔离布局计算和绘制范围

## 功能说明

### 核心功能

- **分类管理** — 内置视角、高度、构图、透视、镜头效果、镜头参数六大默认分类，支持自定义分类
- **提示词管理** — 单个添加、批量导入、编辑和删除，自动去重
- **组合选择** — 勾选提示词实时组合，支持全选/取消全选/清空
- **实时预览** — 选中提示词即时生成组合预览，支持中英文双语
- **随机生成** — 从指定类别随机抽取提示词
- **多格式导出** — 纯文本、JSON、Markdown、CSV 四种格式，可自定义分隔符

### 右键复制

- 勾选"开启右键复制"后，右键提示词立即复制到剪贴板
- 设置中可配置复制内容包含"原词""翻译"及连结符号

### 快捷键导出

- 设置中录制自定义组合键（支持 Ctrl/Shift/Alt/Meta）
- 默认复制到剪贴板，可选导出为 CSV/Markdown/JS 文件

### 搜索功能

- 输入关键词即时显示匹配结果，支持高亮和翻译展示
- 点击搜索结果直接添加/移除提示词

### 排序功能

- A-Z 升序 / Z-A 降序快速排序
- 编辑弹窗中拖拽手柄自由调整顺序

### 批量操作

- 批量移动、删除、修改提示词，带二次确认
- 批量添加、删除分类

### 常用提示词

- 自动记录使用频率，各分类顶部展示 Top N（可配置数量）
- 一键清空使用记录

### 翻译功能

- 离线翻译：内置常用 AI 绘画术语中英对照词典
- 在线翻译：支持 MyMemory API 及自定义翻译 API
- 一键批量翻译所有未翻译的提示词

### 个性化设置

- 背景图片（最大 10MB，文件系统存储）
- 面板风格：磨砂玻璃 / 全透明
- 透明度调节 0-100%
- 背景清晰度优化
- 缓存管理

### 数据管理

- 数据持久化至本地，无需联网
- JSON 导入导出（备份与恢复，支持替换或合并）
- CSV 导入导出
- 重复清理
- 自定义数据存储目录（v1.4 新增）

## 下载与安装

### 方式一：安装版（推荐）

1. 从 [Releases](https://github.com/Luo-fe/ai-prompt/releases) 下载安装版 exe
2. 运行安装程序，按向导完成安装
3. 桌面和开始菜单自动创建快捷方式
4. 若已安装旧版本，安装程序自动检测并迁移用户数据

### 方式二：便携版（zip 解压版，启动最快）

1. 从 [Releases](https://github.com/Luo-fe/ai-prompt/releases) 下载便携版 zip
2. 解压到任意目录
3. 双击 `Luo-fe的本地提示词管理器.exe` 运行，启动时间 < 1 秒
4. 用户数据存储在 exe 同级 `data/` 目录，删除文件夹即可卸载

### 方式三：便携版（单 exe，分发最便）

1. 从 [Releases](https://github.com/Luo-fe/ai-prompt/releases) 下载便携版单 exe
2. 双击即可运行，无需安装
3. 首次运行自动解压到临时目录（约 3-5 秒），后续启动同样需要解压
4. 用户数据存储在 exe 同级 `data/` 目录，删除 exe 即可卸载

### 三种版本对比

| 特性 | 安装版 | 便携版（zip 解压版） | 便携版（单 exe） |
|------|--------|---------------------|-----------------|
| 文件形式 | 安装程序 | 解压后的文件夹 | 单个 exe |
| 启动速度 | < 1 秒 | < 1 秒 | 3-5 秒（需解压） |
| 分发便利 | 一般 | 需传输 zip | 极佳（单文件） |
| 数据存储 | 安装目录/data/ | exe 同级 data/ | exe 同级 data/ |
| 升级迁移 | 支持 | 不适用 | 不适用 |
| 快捷方式 | 桌面+开始菜单 | 无 | 无 |

### 方式四：从源码运行

**环境要求：** Node.js 18+，npm 9+

```bash
git clone https://github.com/Luo-fe/ai-prompt.git
cd ai-prompt
npm install
npm start
```

**打包构建：**

```bash
# 构建全部三个版本（安装版 + 便携版单exe + 便携版zip）
npm run build:all

# 仅构建安装版
npm run build:nsis

# 仅构建便携版单 exe
npm run build:portable

# 仅构建便携版 zip 解压版
npm run build:zip
```

## 技术栈

- **Electron 33** — 桌面应用框架
- **electron-builder 25** — 打包工具（NSIS 安装版 + 便携版单 exe + 便携版 zip）
- **Sharp + to-ico** — 多尺寸图标生成
- **原生 HTML/CSS/JavaScript** — 无额外前端框架，ES Modules 模块化架构
- **localStorage + 文件系统** — 混合存储策略
- **Electron IPC** — 背景图存储、缓存管理、文件导出
- **MyMemory API** — 在线翻译服务

## 性能优化

### v1.4.1 性能优化

全面性能优化，降低内存占用和 CPU 使用率：

- **内存**：LRU 图片缓存（上限 20 条）、防抖保存频率统计
- **CPU**：缓存常用提示词计算、缓存快捷键解析、按需注册鼠标事件、搜索短路优化
- **GPU/渲染**：`content-visibility: auto` 跳过离屏渲染、`contain: layout paint style` 隔离面板重排

详见 [性能优化报告.md](性能优化报告.md)。

### v1.3 启动速度优化

启动时间从 4-6 秒降至 < 1 秒：

- 启动画面最短显示时间 800ms → 400ms
- 缓存并行加载（Promise.all）
- 非关键初始化延迟到 requestIdleCallback
- 禁用后台计时器节流和渲染器后台化

## 升级说明

- 从 v1.2/v1.3 升级至 v1.4+ 时，安装程序自动检测旧版本并迁移用户数据
- 升级过程中提示词、分类、设置、背景图等完整保留
- v1.4+ 支持在设置中自定义数据存储目录

## 注意事项

- 所有提示词和分类数据存储在 localStorage 中，建议定期通过 JSON 导出备份
- 背景图片通过 Electron IPC 存储到用户数据目录，支持最大 10MB
- 缓存文件存储在数据目录的 `cache/` 子目录中
- 在线翻译功能需要网络连接，离线时仅可使用内置词典
- 应用仅支持 Windows x64 系统
