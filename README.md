# Luo-fe 本地提示词管理器 v1.4.8

一款专为 AI 文生图设计的本地提示词管理工具，帮助用户高效组织、选择和导出提示词组合。

## v1.4.8 从分类导入学习样本 + 词典诊断增强

- **从软件分类导入学习样本** — 学习中心新增"从分类导入"按钮，可将软件已有分类（视角/构图/镜头效果等）下的所有提示词一键导入到当前学习类别，自动去重，便于快速构建训练样本
- **词典调用诊断增强** — 修复 `enabled` 字段缺失误启用学习模型的 bug；诊断面板分 6 区块展示词典内存加载状态/学习设置；chip 新增 📖词典/⚙规则来源徽章；工具栏显示 `📖词典数 · ⚙规则数 · 🧠模型数 · ?未识别数` 来源统计

## v1.4.7 本地学习模型辅助分类

新增纯本地、零依赖的机器学习分类模型（多项式朴素贝叶斯），用户可上传各类别提示词样本，一键训练后自动辅助后续导入标签的分类决策：

- **学习算法** — 多项式朴素贝叶斯，纯 JS 实现零依赖；特征提取（整词+子词+字符 3-gram）；拉普拉斯平滑 + softmax 归一化；置信度阈值可调（0.4/0.6/0.8/0.9）
- **分类流程融合** — 4 级匹配优先级：词典精确 → 词典规范化 → 规则 → **学习模型预测（新增）** → 回退；学习模型仅在词典+规则未命中时介入，不覆盖既有结果
- **学习中心 UI** — 左侧类别管理（12 内置 + 自定义类别新建/重命名/删除）+ 右侧样本编辑（textarea 粘贴 + .txt 导入）+ 一键训练/删除模型
- **词典可靠性增强** — asar 二级备份 `src/assets/danbooru-tags-fallback.json`；设置面板新增"词典与模型诊断"按钮

## v1.4.6 本地分词分类器

新增本地、离线、轻量的分词分类器，自动把外部粘贴的逗号分隔标签（Danbooru/Civitai/NovelAI 风格）按语义分组展示，用户在分组结果上即可删除、移动、批量导入到软件已有分类：

- **分类引擎** — 纯函数分类引擎 `classifier-engine.js`，4 步匹配优先级（精确 → 规范化 → 正则规则 → 回退）；内置词典 245 条标签，5 大类 + general 下 8 子组，仅 9.8KB
- **零依赖** — 不引入 ONNX/TFJS 等重型 ML 库，保持极简依赖
- **chip 交互** — 圆角胶囊样式，左侧类别色条；单击切换选中、× 删除、已导入淡色勾标、未识别角标
- **自定义规则** — JSON 编辑器编辑自定义分类规则，与内置词典合并，customRules 优先覆盖

## v1.4.5 布局系统重构：比例联动 + 消除滚动条

全面重构布局系统，改用 flex-grow 比例模型替代固定像素宽度，彻底解决滚动条和拖拽跟手问题：

- **比例联动调整** — 拖拽一个卡片边框时，相邻卡片自动联动缩小/放大，三个卡片始终横向占满软件界面，不超出画面
- **flex-grow 比例模型** — 布局数据从固定像素宽度改为 ratio 比例（默认 20:50:30），窗口缩放时三个卡片等比例横向缩放，始终保持占满界面
- **锁死布局 = 比例锁定** — 开启锁死布局后记录的是卡片间的比例关系，软件界面放大或缩小时卡片等比例缩放，布局结构不变
- **消除全局滚动条** — body/main-content/面板均设 `overflow: hidden`，面板内部内容区独立滚动（鼠标下滑），不再出现页面级滚动条
- **右侧面板双滚动条修复** — 预览面板改为 flex column 布局，内部新增 `.preview-scroll-content` 滚动区，消除嵌套滚动条
- **拖拽跟手优化** — 移除 RAF 节流，拖拽时直接更新 CSS 变量（`--layout-*-ratio`），浏览器仅重算 flex 布局，响应极快
- **移除 max-height 约束** — `.category-list`、`.prompt-list` 等内部列表改用 `flex: 1` 填充剩余空间，不再使用 `calc(100vh - XXpx)`

## v1.4.3 布局自定义与升级安装优化

新增主界面卡片布局自定义功能，并改进升级安装流程：

- **卡片布局自定义** — 设置面板新增"布局自定义"区域，点击"卡片布局自定义"进入编辑模式，可自由调整类别卡片、提示词卡片、已选提示词卡片（整个右侧面板）的相对位置和大小
- **拖拽换位** — 编辑模式下，拖拽卡片顶部的手柄即可交换卡片位置，配以 FLIP 动画实现平滑过渡
- **拖拽边框调整大小** — 编辑模式下，类别卡片和预览卡片右侧显示蓝色 resize 手柄，拖拽可调整宽度，提示词卡片自动占位
- **锁死布局** — 开启后禁用响应式布局，窗口大小变化时卡片布局和相对位置保持不变，但卡片内部内容仍可自适应（防止出现滚动条）
- **恢复默认布局** — 一键恢复到软件默认的卡片布局和位置，并自动解除锁死布局
- **跨重启持久化** — 自定义布局保存后，重启软件仍保持用户的布局设置
- **编辑模式 UI 动画** — 编辑模式下卡片显示脉冲虚线边框，手柄渐入，底部工具栏平滑滑入
- **升级安装检测优化** — 升级安装时自动检测旧版本安装位置并默认安装到同一目录
- **升级时保留数据删除旧程序** — 升级安装时自动删除旧版本程序本体（exe/dll/resources 等），严格保留 data/ 数据文件夹

针对提示词选中与批量操作的视觉冗余和交互冲突进行优化：

- **移除选中卡片右上角对勾** — 选中状态此前同时显示复选框、边框变色、右上角对勾三个指示，现移除右上角对勾，仅保留复选框与边框变色，视觉更简洁

## v1.4.1 性能优化

全面性能优化，降低运行时内存占用和 CPU 使用率，所有功能保持不变：

- **LRU 图片缓存** — 提示词图片缓存从无上限改为 LRU 策略（最大 20 条），消除内存泄漏
- **防抖保存频率** — 提示词使用记录保存改为防抖机制，I/O 频率降低 90%+
- **缓存常用提示词** — 常用提示词计算结果缓存，避免每次渲染重复扫描
- **按需注册鼠标事件** — 面板拖拽的 mousemove/mouseup 监听器改为仅在拖拽时注册，空闲时零开销
- **缓存快捷键解析** — 快捷键字符串解析结果缓存，避免每次按键重复解析
- **搜索短路优化** — 搜索时避免冗余 `toLowerCase()` 调用，text 已匹配时跳过翻译检查
- **离屏渲染跳过** — 滚动列表添加 `content-visibility: auto`，浏览器自动跳过离屏元素渲染
- **面板渲染隔离** — 面板添加 `contain: layout paint style`，隔离布局计算和绘制范围

## 下载与安装

### 方式一：安装版（推荐）

1. 从 [Releases](https://github.com/Luo-fe/ai-prompt/releases) 下载安装版 exe
2. 运行安装程序，按向导完成安装
3. 桌面和开始菜单自动创建快捷方式
4. 若已安装旧版本，安装程序自动检测并迁移用户数据

### 方式二：便携版（zip 解压版，启动最快）

1. 从 [Releases](https://github.com/Luo-fe/ai-prompt/releases) 下载便携版 zip
2. 解压到任意目录
3. 双击 `Luo-fe的本地提示词管理器.exe` 运行，启动时间 < 1 秒
4. 用户数据存储在 exe 同级 `data/` 目录，删除文件夹即可卸载

### 方式三：便携版（单 exe，分发最便）

1. 从 [Releases](https://github.com/Luo-fe/ai-prompt/releases) 下载便携版单 exe
2. 双击即可运行，无需安装
3. 首次运行自动解压到临时目录（约 3-5 秒），后续启动同样需要解压
4. 用户数据存储在 exe 同级 `data/` 目录，删除 exe 即可卸载

### 三种版本对比

| 特性 | 安装版 | 便携版（zip 解压版） | 便携版（单 exe） |
|------|--------|---------------------|-----------------|
| 文件形式 | 安装程序 | 解压后的文件夹 | 单个 exe |
| 启动速度 | < 1 秒 | < 1 秒 | 3-5 秒（需解压） |
| 分发便利 | 一般 | 需传输 zip | 极佳（单文件） |
| 数据存储 | 安装目录/data/ | exe 同级 data/ | exe 同级 data/ |
| 升级迁移 | 支持 | 不适用 | 不适用 |
| 快捷方式 | 桌面+开始菜单 | 无 | 无 |

### 方式四：从源码运行

**环境要求：** Node.js 18+，npm 9+

```bash
git clone https://github.com/Luo-fe/ai-prompt.git
cd ai-prompt
npm install
npm start
```

**打包构建：**

```bash
# 构建全部三个版本（安装版 + 便携版单exe + 便携版zip）
npm run build:all

# 仅构建安装版
npm run build:nsis

# 仅构建便携版单 exe
npm run build:portable

# 仅构建便携版 zip 解压版
npm run build:zip
```

- 启动画面最短显示时间 800ms → 400ms
- 缓存并行加载（Promise.all）
- 非关键初始化延迟到 requestIdleCallback
- 禁用后台计时器节流和渲染器后台化

## 升级说明

- 从 v1.2/v1.3 升级至 v1.4+ 时，安装程序自动检测旧版本并迁移用户数据
- 升级过程中提示词、分类、设置、背景图等完整保留
- v1.4+ 支持在设置中自定义数据存储目录

## 注意事项

- 所有提示词和分类数据存储在 localStorage 中，建议定期通过 JSON 导出备份
- 背景图片通过 Electron IPC 存储到用户数据目录，支持最大 10MB
- 缓存文件存储在数据目录的 `cache/` 子目录中
- 在线翻译功能需要网络连接，离线时仅可使用内置词典
- 应用仅支持 Windows x64 系统
