# Luo-fe 本地提示词管理器 v1.2

一款专为 AI 文生图设计的本地提示词管理与组合工具，帮助用户高效组织、选择和导出提示词组合。

## ✨ v1.2 新功能

- **启动画面** — 双击后立即显示美观的启动加载画面，包含应用名称、版本号和加载动画，提升启动体验
- **提示词搜索** — 实时搜索提示词，支持关键词高亮、翻译展示、快捷选择，搜索结果自动同步已选状态
- **提示词排序** — 编辑弹窗中支持 A-Z/Z-A 一键排序及拖拽自定义排序
- **批量操作** — 批量移动、删除、修改提示词，带确认机制防止误操作
- **分类管理增强** — 支持批量添加/删除分类、分类排序，操作后所有面板实时同步更新
- **常用提示词** — 自动统计使用频率，展示各分类 Top N 常用提示词
- **背景清晰度优化** — 为卡片添加毛玻璃背景、阴影和文字对比度增强
- **卡片自适应布局** — 提示词卡片根据内容长度自适应大小，窗口缩放时保持美观
- **本地缓存加速** — 设置信息本地缓存，热启动速度显著提升，缓存文件存储在应用同级目录
- **背景图文件存储** — 背景图改用文件系统存储，不再受 localStorage 5MB 限制，最多支持 10MB

## 功能说明

### 核心功能

- **分类管理** — 内置视角、高度、构图、透视、镜头效果、镜头参数六大默认分类，支持自定义分类的创建、编辑、删除、批量操作和排序
- **提示词管理** — 支持单个添加、批量导入、编辑和删除提示词，自动去重
- **组合选择** — 勾选提示词实时组合，支持全选/取消全选/清空操作
- **实时预览** — 选中提示词即时生成组合预览，支持中英文双语显示
- **随机生成** — 从指定类别中随机抽取提示词，激发创作灵感，类别选择与分类管理实时同步
- **多格式导出** — 支持纯文本、JSON、Markdown 三种格式导出，可自定义分隔符

### 搜索功能

- **实时搜索** — 输入关键词即时显示匹配结果
- **结果展示** — 显示提示词文本（高亮匹配）、翻译内容、所属类别
- **快捷选择** — 点击搜索结果直接添加/移除提示词
- **状态同步** — 已选提示词在搜索结果中自动标记

### 排序功能

- **一键排序** — A-Z 升序 / Z-A 降序快速排序
- **拖拽排序** — 在编辑弹窗中拖拽手柄自由调整顺序

### 批量操作

- **批量移动** — 将多个提示词同时移动到其他分类
- **批量删除** — 一次性移除多个选中的提示词
- **批量修改** — 为多个提示词统一添加前缀
- **批量分类管理** — 支持批量添加、批量删除分类
- **确认机制** — 所有批量操作均有二次确认，防止误操作

### 常用提示词

- **使用统计** — 自动记录提示词使用频率
- **Top N 展示** — 各分类顶部展示最常用的提示词（默认前10个）
- **自定义数量** — 设置中可调整常用提示词显示数量
- **清空记录** — 一键清空使用记录（带二次确认）

### 翻译功能

- **离线翻译** — 内置常用 AI 绘画术语中英对照词典
- **在线翻译** — 支持 MyMemory 翻译 API 及自定义翻译 API
- **一键翻译** — 批量翻译所有未翻译的提示词
- **手动编辑** — 点击翻译文本即可手动编辑翻译内容

### 个性化设置

- **背景图片** — 支持自定义背景图片（最大10MB），文件系统存储不丢失
- **面板风格** — 磨砂玻璃效果 / 全透明效果两种风格可选
- **透明度调节** — 面板透明度 0-100% 实时调节
- **背景清晰度优化** — 为卡片添加毛玻璃背景、阴影和文字增强，解决背景图干扰阅读问题
- **缓存管理** — 设置面板中可查看缓存信息、手动清除缓存

### 数据管理

- **数据持久化** — 所有数据自动保存至本地，无需联网
- **JSON 导入导出** — 支持完整数据的备份与恢复，可选择替换或合并
- **CSV 导入导出** — 支持以 CSV 格式导入导出提示词数据，导入后界面自动刷新
- **重复清理** — 一键清理分类中的重复提示词
- **本地缓存** — 设置和配置信息本地缓存，加速热启动，缓存文件仅存储在应用同级目录

## 使用方法

### 基本操作流程

1. 从左侧分类列表选择一个分类
2. 在中间面板勾选需要的提示词（或使用搜索功能查找）
3. 右侧面板实时显示已选提示词和组合预览
4. 点击「导出提示词」按钮选择格式并导出

### 搜索提示词

1. 在提示词面板顶部的搜索栏输入关键词
2. 搜索结果实时显示匹配的提示词
3. 点击搜索结果可直接选择/取消选择

### 分类管理

1. 点击左侧「新增分类」按钮打开分类管理弹窗
2. 支持单个添加、批量添加（每行一个名称）
3. 勾选分类后可批量删除
4. 每个分类支持上移/下移排序
5. 所有操作后随机生成面板的分类选择自动同步更新

### 批量操作

1. 点击「批量操作」按钮进入批量模式
2. 勾选需要操作的提示词
3. 选择移动到/删除/批量修改操作
4. 确认操作后自动退出批量模式

### 背景与显示

1. 点击顶部「设置」按钮
2. 在「背景设置」区域上传背景图片
3. 选择面板风格（磨砂玻璃/全透明）
4. 拖动透明度滑块调节面板透明度
5. 如背景图影响阅读，点击「背景图清晰度优化」按钮

## 安装步骤

### 方式一：安装版（推荐）

1. 从 [Releases](https://github.com/Luo-fe/ai-prompt/releases) 页面下载最新版安装版 exe
2. 运行安装程序，按向导完成安装
3. 安装完成后桌面和开始菜单自动创建快捷方式
4. 任务管理器中正确显示应用名称和图标

### 方式二：从源码运行

**环境要求：**

- Node.js 18+
- npm 9+

**步骤：**

```bash
git clone https://github.com/Luo-fe/ai-prompt.git
cd ai-prompt
npm install
npm start
```

**打包构建：**

```bash
# 生成安装版 + 便携版
npm run build:all

# 仅生成安装版
npm run build:nsis

# 仅生成便携版
npm run build
```

## 技术栈

- **Electron 33** — 桌面应用框架
- **Sharp + to-ico** — 多尺寸图标生成
- **原生 HTML/CSS/JavaScript** — 无额外前端框架依赖，模块化架构
- **localStorage + 文件系统** — 混合存储策略
- **Electron IPC** — 背景图文件系统存储、缓存管理
- **MyMemory API** — 在线翻译服务
- **Crypto (MD5)** — 缓存完整性校验

## 注意事项

- 所有提示词和分类数据存储在浏览器 localStorage 中，建议定期通过 JSON 导出备份
- 背景图片通过 Electron IPC 存储到用户数据目录，不再受 localStorage 5MB 限制，最多支持 10MB
- 缓存文件存储在应用同级目录的 `data/cache/` 中，不会在 C 盘或其他系统目录创建文件
- 在线翻译功能需要网络连接，离线时仅可使用内置词典翻译
- 应用仅支持 Windows x64 系统
