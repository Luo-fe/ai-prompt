# Luo-fe 本地提示词管理器 v1.1

一款专为 AI 文生图设计的本地提示词管理与组合工具，帮助用户高效组织、选择和导出提示词组合。

## 功能说明

### 核心功能

- **分类管理** — 内置视角、高度、构图、透视、镜头效果、镜头参数六大默认分类，支持自定义分类的创建、编辑和删除
- **提示词管理** — 支持单个添加、批量导入、编辑和删除提示词，自动去重
- **组合选择** — 勾选提示词实时组合，支持全选/取消全选/清空操作
- **实时预览** — 选中提示词即时生成组合预览，支持中英文双语显示
- **随机生成** — 从指定类别中随机抽取提示词，激发创作灵感
- **多格式导出** — 支持纯文本、JSON、Markdown 三种格式导出，可自定义分隔符

### 翻译功能

- **离线翻译** — 内置常用 AI 绘画术语中英对照词典
- **在线翻译** — 支持 MyMemory 翻译 API 及自定义翻译 API
- **一键翻译** — 批量翻译所有未翻译的提示词
- **手动编辑** — 点击翻译文本即可手动编辑翻译内容

### 个性化设置

- **背景图片** — 支持自定义背景图片，JPG/PNG/BMP/WebP/GIF 格式
- **面板风格** — 磨砂玻璃效果 / 全透明效果两种风格可选
- **透明度调节** — 面板透明度 0-100% 实时调节，拖动滑块即时生效
- **翻译开关** — 可独立控制翻译功能的各项子选项

### 数据管理

- **数据持久化** — 所有数据自动保存至本地，无需联网
- **JSON 导入导出** — 支持完整数据的备份与恢复，可选择替换或合并
- **CSV 导入导出** — 支持以 CSV 格式导入导出提示词数据
- **重复清理** — 一键清理分类中的重复提示词

## 使用方法

### 基本操作流程

1. 从左侧分类列表选择一个分类
2. 在中间面板勾选需要的提示词
3. 右侧面板实时显示已选提示词和组合预览
4. 点击「导出提示词」按钮选择格式并导出

### 快捷操作

- 点击提示词行即可快速选中/取消
- 使用「全选」快速选中当前分类所有提示词
- 使用「随机来一组」从指定类别随机生成组合

### 自定义分类

1. 点击左侧「新增分类」按钮
2. 输入分类名称并确认
3. 在新分类中添加提示词（支持单个添加和批量导入）

### 背景与透明度

1. 点击顶部「设置」按钮
2. 在「背景设置」区域上传背景图片
3. 选择面板风格（磨砂玻璃/全透明）
4. 拖动透明度滑块实时调节面板透明度

## 安装步骤

### 方式一：便携版（推荐）

1. 从 [Releases](https://github.com/Luo-fe/ai-prompt/releases) 页面下载最新版便携版 exe
2. 双击运行即可，无需安装

### 方式二：从源码运行

**环境要求：**

- Node.js 16+
- npm 8+

**步骤：**

```bash
# 克隆仓库
git clone https://github.com/Luo-fe/ai-prompt.git
cd ai-prompt

# 安装依赖
npm install

# 开发模式运行
npm start

# 打包为 exe
npm run build
```

## 技术栈

- **Electron** — 桌面应用框架
- **原生 HTML/CSS/JavaScript** — 无额外前端框架依赖
- **localStorage** — 本地数据持久化
- **MyMemory API** — 在线翻译服务

## 注意事项

- 所有数据存储在浏览器 localStorage 中，清除浏览器数据会导致数据丢失，建议定期使用导出功能备份
- 在线翻译功能需要网络连接，离线时仅可使用内置词典翻译
- 背景图片会以 Base64 格式存储在 localStorage 中，建议使用不超过 5MB 的图片
- 便携版 exe 仅支持 Windows 系统
- 首次使用在线翻译时，API 请求可能有短暂延迟
